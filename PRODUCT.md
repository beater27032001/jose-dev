## Product Purpose

Portfólio pessoal de José Carlos Paiva Santos (José Paiva), Engenheiro de Software Full-Stack em Recife. Sucesso: o visitante sai sabendo quem ele é, o que já colocou em produção e como contatá-lo, e lembra do formato.

## Positioning

O portfólio é um editor de código que funciona: arquivos, abas, paleta de comandos, terminal com comandos e tema claro/escuro. O visitante navega a carreira do José do jeito que um dev navega um repositório. O formato demonstra o ofício em vez de descrevê-lo.

## Operating Context

Visitado a partir do LinkedIn, do CV (link josepaivadev.com) e de candidaturas. Recrutadores abrem no desktop e no celular; tech leads tendem a explorar terminal e paleta.

## Capabilities and Constraints

- Conceito fixo, definido pelo dono: interface de editor no estilo VS Code (barra de atividade, explorador, abas, editor com destaque de sintaxe e pré-visualização de Markdown, terminal, barra de status, paleta de comandos, tema claro e escuro).
- Precisa funcionar e ser usável no celular.
- Sem a parte "técnica" de como a página foi feita (o original tinha `COMO-FOI-FEITO.md`; não entra).
- Projetos em duas pastas: `trabalho/` (produtos reais em produção) e `experimentos/` (páginas de portfólio).
- Os experimentos estão publicados (Vercel) com código aberto no GitHub (repositórios públicos desde 2026-11-07); os links ficam em `src/domain/profile.ts`.
- Canais de contato exibidos: e-mail, LinkedIn, GitHub e CV em PDF (decisão do dono). Telefone e WhatsApp não aparecem na página.
- Primeira tela: README.md em pré-visualização, como boas-vindas (decisão do dono).
- No celular: editor completo adaptado, com o explorador em gaveta (decisão do dono).

## Product Principles

1. O formato é a prova: tudo que é clicável no editor faz alguma coisa de verdade.
2. Fatos verificáveis acima de autoelogio: cargos, datas, stacks e produtos reais.
3. Rápido de escanear para o recrutador, rico para quem quer explorar.
4. Funciona igualmente bem no celular.
